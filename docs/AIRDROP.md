# Nearby AirDrop

**Mac:** Use **Send via AirDrop** or **Paste via AirDrop** in the + menu. macOS shows the device picker and handles incoming AirDrops.

**Linux:** Install [Owly and its radio service](https://github.com/t4t5/owly#install), then open **Nearby AirDrop** in myDrive. Choose files or a folder to send, or choose **Receive** to accept a nearby offer. The radio session ends when you close the dialog or when ten minutes pass. Some adapters need to pause Wi-Fi during the session. If the computer does not appear, check the [Owly troubleshooting guide](https://github.com/t4t5/owly#known-issues).

**Windows 11:** Install [WirDrop and a supported USB Wi-Fi adapter](https://github.com/JungyoKim/WirDrop#what-you-need), then open **Nearby AirDrop** in myDrive. WirDrop shows the picker and handles incoming AirDrops.

Apple devices can ask for an AirDrop code. Support for sending and receiving with non-Apple hardware varies with the helper, radio, and Apple software version. [Apple’s AirDrop guide](https://support.apple.com/guide/mac-help/mh35868/mac)
