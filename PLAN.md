# myDrive

Product name: **myDrive**.

The current Windows preview uses a compact system tray popup for everyday tasks, with an optional full window displaying the same features. Native platform UIs and a shared Rust core remain the architecture.

- [ROADMAP.md](ROADMAP.md): completed work and remaining implementation milestones.
- [docs/REFERENCE-PLAN.md](docs/REFERENCE-PLAN.md): original supplied specification, retained verbatim as reference material.
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): current implementation and its boundaries.
- [docs/VALIDATION.md](docs/VALIDATION.md): checks performed on this build.
- [docs/NATIVE-UI.md](docs/NATIVE-UI.md): priority for a small, dense native popup on Windows, macOS and Linux.
